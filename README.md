# odin-recipes
use HTML to build a recipe website with a main index page with several recipe pages.

While creating in this project I used html code to build out a homepage for Odin Thanksgiving Recipes, then coded 5 recipe pages based on America's Test Kitchen Thanksgiving. On each page I created headings and paragraphs. I also used emphasis and bolding to make ingredients and other details stand out. I was able to add photos and links on each page as well. While visually plain, I learned about how to make a full html site that is consistent and functional.
